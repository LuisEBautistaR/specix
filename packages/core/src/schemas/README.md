# Esquemas oficiales

Copias sin modificar de los esquemas JSON publicados por los autores de cada especificación. Specix los usa para la validación estructural (`validate.ts`).

| Archivo | Origen | Licencia |
|---|---|---|
| `openapi-2.0.json` | https://spec.openapis.org/oas/2.0/schema/2017-08-27 | Apache-2.0 (OpenAPI Initiative) |
| `openapi-3.0.json` | https://spec.openapis.org/oas/3.0/schema/2024-10-18 | Apache-2.0 (OpenAPI Initiative) |
| `openapi-3.1.json` | https://spec.openapis.org/oas/3.1/schema/2026-08-03 | Apache-2.0 (OpenAPI Initiative) |
| `openapi-3.2.json` | https://spec.openapis.org/oas/3.2/schema/2026-08-30 | Apache-2.0 (OpenAPI Initiative) |
| `asyncapi-<versión>.json` | https://github.com/asyncapi/spec-json-schemas, carpeta `schemas/` | Apache-2.0 (AsyncAPI Initiative) |

Para actualizar uno, descarga la nueva fecha o versión y cambia la tabla de `validate.ts`.
